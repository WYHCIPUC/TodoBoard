# v2.4.0：纸间灵感研究室

发布日期：2026-10-28。

## 这次更新了什么

v2.4.0 是一次完整的前端设计与真实交互升级。新版本以“本地研究档案”为中心，用暖纸色、墨色、朱橙、编辑式分隔线和编号索引建立统一视觉语言，减少层层卡片、重复装饰和过小文字。

- 首屏改为任务导向的“灵感项目库”，让真实收藏、研究进度与主要操作更早出现。
- 列表直接呈现摘要、分类、来源与归档状态；看板卡片、搜索、筛选、空态和每日建议使用同一信息层级。
- 关系画布按真实节点范围缩放，保留来源筛选、拖拽归位、离线关系、详情和移动抽屉。
- 头脑风暴按需求、证据、融合方案和验证步骤组织内容；研究档案采用桌面双栏与移动单栏布局。
- 四种主题、弹窗、表单、加载、空数据、错误、禁用与成功状态统一；补齐键盘菜单、焦点恢复和跨工作区视图状态。
- 浅色辅助文字和分类色加入对比度自动检查，真实浏览器覆盖桌面、平板、390px 手机、离线和减少动态效果。

## 桌面资产与数据位置

- `linggankanban-2.4.0-windows-x64.exe`：Windows 10/11 x64 单文件桌面客户端。
- `linggankanban-2.4.0-windows-portable-x64.zip`：内置固定 Node.js 24.16.0 的便携版。
- `linggankanban-2.4.0-windows.zip`：源码运行包。
- 两个 manifest：分别记录源码包与便携包的逐文件大小和 SHA-256。
- `SHA256SUMS.txt`：以上安装资产和 manifest 的完整性校验。

单文件版把程序缓存放在 `%LOCALAPPDATA%\LingganKanban\app`，个人数据放在 `%USERPROFILE%\Documents\LingganKanban`。替换 EXE 不会覆盖个人数据。便携版和源码版默认在应用目录保存数据；升级前仍建议复制整个数据目录。

## 兼容、恢复与限制

- 源码需要 Node.js 22 或 24；没有新增运行时依赖，不要求 API Key 或远程字体。
- `DATA.md` 格式、业务 API、条目 UID、归档、备份与恢复合同保持兼容，不要求重新迁移。
- 网络失败、只读服务、归档降级和离线基础关系仍明确显示；恢复仍需只读预览、显式候选和写后验证。
- EXE 目前未使用商业代码签名。请只从本仓库 Release 下载，并使用 `SHA256SUMS.txt` 校验完整性。
- 当前 Windows EXE 验证环境为 Windows 11；Windows 10 干净实机/VM 与另一个全新 Windows 用户账户的人工步骤未覆盖，不能视为已经验证。详细结果以发布门禁证据为准。
