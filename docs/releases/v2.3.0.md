# v2.3.0：三阶段灵感工作台

发布日期：2026-08-29。

## 这次更新了什么

v2.3 把产品主线收束为“灵感来袭 → 关系画布 → 头脑风暴”。新增内容从明确可见的收藏入口进入本地项目库，后台继续主动归档正文与元数据；关系画布负责按主题整理、筛选、缩放、拖拽和追溯；头脑风暴从真实问题出发，把已有来源组合成带依据的候选方案和最小验证步骤。

界面统一了按钮按压、异步忙碌状态、Toast、弹层、窄屏抽屉和减少动态效果。识别、保存、备份、关系分析、研究档案与方案生成都会阻止重复提交，并在成功或失败后恢复真实可操作状态。X / Twitter 的三条公开解析路径改为并行执行，降低网络受限时的累计等待；外部解析失败仍先保留链接和可识别信息。

## 桌面资产与数据位置

- `linggankanban-2.3.0-windows-x64.exe`：Windows 10/11 x64 单文件桌面客户端。
- `linggankanban-2.3.0-windows-portable-x64.zip`：内置固定 Node.js 24.16.0 的便携版。
- `linggankanban-2.3.0-windows.zip`：源码运行包。
- `SHA256SUMS.txt`：以上资产和 manifest 的完整性校验。
- `linggan-v2.3-update.mp4`：新版介绍视频（BGM + SFX）。
- `linggan-v2.3-update-nobgm.mp4`：同画面仅保留 SFX 的备用版本。
- `VIDEO-SHA256SUMS.txt`：两版视频的完整性校验。

单文件版把程序缓存放在 `%LOCALAPPDATA%\LingganKanban\app`，个人数据放在 `%USERPROFILE%\Documents\LingganKanban`。替换 EXE 不会覆盖个人数据。便携版和源码版默认在应用目录保存数据；升级前仍建议复制整个数据目录。

## 兼容、恢复与限制

源码需要 Node.js 22 或 24。恢复默认只读；证据不明确、数据正在使用或验证失败时停止，不猜测候选、不自动覆盖。v2.2 建立的事务、快照、幂等和恢复收据继续兼容。

核心收集、整理和头脑风暴不要求 API Key。网页解析受登录、限流、网络和页面变化影响；应用不会绕过登录或付费访问控制，也不提供云同步或多人协作。EXE 目前可能没有商业代码签名，请只从本仓库 Release 下载并核对 SHA-256。

## 发布验证

正式资产已通过 `npm run check`、固定 scraper 测试、真实浏览器 E2E、launcher 测试、两次确定性构建对比以及单文件 EXE 离线 smoke。安装资产哈希以本次 GitHub Release 中的 `SHA256SUMS.txt` 为准；发布演练还确认全新解压、固定运行时、离线启动与写入均正常，且仓库 `DATA.md` 未改变。
