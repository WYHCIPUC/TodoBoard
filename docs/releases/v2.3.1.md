# v2.3.1：升级安全、只读保护与界面闭环

发布日期：2026-10-24。

## 这次更新了什么

v2.3.1 是 v2.3.0 的维护版本，重点补齐“数据升级与恢复”和“验证闭环”两块：

- 启动接入 `bootstrap` / `runUpgrade`：同一数据目录实例锁、全数据卷锁、旧进程端口审计、可信写恢复、归档事务恢复，以及已有数据首次启动的升级前完整快照。
- 实例锁冲突不再直接退出，而是启动**只读看板**：读取、搜索和浏览继续可用，所有写入返回 503；关闭旧实例后重启恢复写入。
- 升级/恢复前检查磁盘空间；空间不足时 fail closed，不创建半成品快照。
- 升级快照恢复与 remigrate CLI：显式快照 SHA-256、`--apply --interactive`、运行中实例拒绝、恢复前 rescue 快照。
- 待处理中心、研究回顾计划、归档完整性巡检接入界面。
- 头脑风暴方案支持待验证/已验证/被否定、验证结果、复盘日期和来源证据覆盖率；历史验证结论参与后续方案置信度与评分。
- 企业微信与钉钉统一远程采集契约：只接受 http(s) 链接和受限来源名，去重、限流、来源记录与最小权限由统一入口负责。
- 归档队列成功任务字段压缩；浏览器端按核心、关系、头脑风暴、数据、研究、快捷指令、研究档案拆分，样式同步拆分。
- 新增收藏、研究笔记、截图、回收站、备份恢复五条主路径真实浏览器测试，以及 1000 条规模验收。

## 桌面资产与数据位置

- `linggankanban-2.3.1-windows-x64.exe`：Windows 10/11 x64 单文件桌面客户端。
- `linggankanban-2.3.1-windows-portable-x64.zip`：内置固定 Node.js 24.16.0 的便携版。
- `linggankanban-2.3.1-windows.zip`：源码运行包。
- `SHA256SUMS.txt`：以上资产和 manifest 的完整性校验。

单文件版把程序缓存放在 `%LOCALAPPDATA%\LingganKanban\app`，个人数据放在 `%USERPROFILE%\Documents\LingganKanban`。替换 EXE 不会覆盖个人数据。便携版和源码版默认在应用目录保存数据；升级前仍建议复制整个数据目录。

## 兼容、恢复与限制

- 源码需要 Node.js 22 或 24；运行时仍为零新增依赖。
- `DATA.md` 格式保持 v2；升级 marker/快照合同保持 `2.2.0`，不要求存量用户重新迁移。
- 恢复默认只读；证据不明确、数据正在使用或验证失败时停止，不猜测候选、不自动覆盖。
- 首次按本版本启动已有数据时会自动创建升级前完整快照；升级/恢复前仍建议额外复制整个数据目录。
- EXE 目前未使用商业代码签名，请只从本仓库 Release 下载并核对 `SHA256SUMS.txt`；签名评估见[代码签名评估](../plans/2026-10-24-code-signing-evaluation.md)。
- 核心收集、整理和头脑风暴不要求 API Key；网页解析受登录、限流、网络和页面变化影响，不绕过登录或付费访问控制。
- Windows 10 实机/VM 人工验证尚未执行；本版本已完成 Windows 11 上的 EXE smoke、fresh extraction 和 Playwright 恢复演练。正式发布前仍需按发布清单补做 Windows 10 验证。
