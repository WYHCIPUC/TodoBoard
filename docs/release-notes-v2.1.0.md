# 灵感工作台 2.1.0

本版本重点解决“收藏后长期不看，原链接后来失效”的问题：链接会先保存到本机，再由后台主动归档主要内容。GitHub 与 X / Twitter 的解析路径也得到加强。

## 下载

- `linggankanban-2.1.0-windows-portable-x64.zip`：公开便携版，解压后双击 `start-portable.bat`，无需安装 Node.js。
- `linggankanban-2.1.0-windows-x64.exe`：Windows x64 单文件版，双击即可运行。
- `linggankanban-2.1.0-windows.zip`：源码运行包，需要 Node.js 20 或更高版本。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。

## 主要变化

- 保存 URL 后立即返回，后台归档可读正文、标题、作者、摘要、关键图片和压缩原始 HTML。
- 归档任务支持重启恢复，以及立即、5 分钟、1 小时、24 小时四次自动尝试。
- 看板显示归档状态、失败原因和下次重试时间，并支持手动重试和正文补录。
- GitHub 解析支持默认分支、限流降级和 README 路径/大小写发现。
- X / Twitter 使用专用解析器；受限内容可以临时配置 `X_COOKIE`，该值不会写入本地文件或发布包。
- 企业微信、钉钉和书签导入统一使用“先保存、后归档”流程。
- 完整备份包含链接归档；发布包排除用户数据、队列、Cookie、日志和宣传素材。

## 升级说明

程序与用户数据保持分离。升级前建议导出完整备份，停止旧版本，再将新版本解压到新目录或替换 EXE。首次启动后确认条目与研究档案无误；未完成的归档任务会从本地队列恢复。

## 已知限制

- 外部站点删除内容、要求登录或限制自动访问时，系统只能保留已经取得的内容；可在条目详情中手动补录正文。
- 企业微信手机分享需要一个企业微信自建应用，以及企业微信服务器可访问的 HTTPS 回调地址。
- X / Twitter 页面结构和访问策略可能变化；`X_COOKIE` 仅作为可选环境变量使用，不应写入启动脚本或仓库。
- Windows EXE 尚未购买商业代码签名证书，请从可信地址下载并核对 `SHA256SUMS.txt`。
