# 📱 钉钉机器人「转发即记录」配置指南

**零域名、零公网、零 cpolar、零封号风险**——通过钉钉 Stream 模式（WebSocket 长连接）接收消息，你的本地看板直接连钉钉，不需要任何公网暴露。

## 工作原理

```
你在钉钉给机器人发链接
        ↓
钉钉服务器 ──WebSocket──→ 你的本地看板（lib/dingtalk.js）
                              ↓
                        抓取元数据 + 写入 DATA.md
                              ↓
                        通过 sessionWebhook 回复"✅ 已记录"
```

## 第 1 步：成为钉钉开发者（个人免费）

1. 手机装「**钉钉**」App，用手机号注册
2. 电脑打开 **https://open-dev.dingtalk.com/**
3. 用钉钉扫码登录 → 会提示「**创建团队/企业**」
   - 选「**个人/小团队**」类型
   - 团队名随便填（如「我的工作室」）
   - 创建完成（免费、无需营业执照）

## 第 2 步：创建企业内部应用

1. 登录 **https://open-dev.dingtalk.com/** 开发者后台
2. 点「**应用开发**」→「**企业内部开发**」→「**创建应用**」
   - 应用名称：`灵感收集`（或任意）
   - 应用描述：随便
   - 应用图标：随便传
   - 开发管理：选「**开发者**」
   - 点「**确认创建**」
3. 进入应用 →「**凭证与基础信息**」，记下两个值：
   - **AppKey**（即 ClientID）
   - **AppSecret**（即 ClientSecret，点"查看"获取）

## 第 3 步：开启机器人能力（Stream 模式）

1. 应用左侧菜单 →「**应用能力**」→「**机器人**」
2. 点「**开启机器人**」
   - 机器人名称：`灵感收集`
   - 消息接收模式：**务必选「Stream 模式」** ← 关键！
   - 其他默认
   - 保存
3. （可选）点「**点击调试**」可创建测试群

## 第 4 步：发布应用

1. 应用左侧 →「**版本管理与发布**」
2. 点「**确认发布**」
3. 可见范围：选「**全部员工**」（就你一人）
4. 发布

## 第 5 步：配置启动脚本

在项目目录创建 `start-dingtalk.bat`（Windows）：

```bat
@echo off
chcp 65001 >nul 2>nul
title Todo Board (钉钉)
cd /d "%~dp0"

set DINGTALK_CLIENT_ID=你的AppKey
set DINGTALK_CLIENT_SECRET=你的AppSecret

echo 正在启动看板服务（钉钉模式）...
echo 启动后会自动连接钉钉，给机器人发链接即可入库
echo.
node server.js
pause
```

> 这个文件名已被 `.gitignore` 忽略，密钥不会上传 GitHub。

## 第 6 步：启动 + 测试

1. 双击 `start-dingtalk.bat`
2. 控制台应显示：
   ```
   钉钉转发入库: 启动中...
   [dingtalk] Stream 客户端已连接，等待消息...
   钉钉 Stream 已就绪，给机器人发链接即可入库
   ```
3. 打开钉钉 App → 找到「灵感收集」机器人（在通讯录或搜索）
4. 发消息：
   ```
   看看这个 https://github.com/mozilla/readability
   ```
5. 几秒后收到回复：
   ```
   ⏳ 正在抓取并记录...
   ✅ 已记录
   1.1 mozilla/readability
   分类：开源项目 & 开发
   作者：mozilla
   ```
6. 看板 http://127.0.0.1:3865 出现新条目 🎉

## 日常使用

- **每天用之前**：双击 `start-dingtalk.bat`（只此一步，不需要 cpolar）
- **关闭**：关掉控制台窗口
- 钉钉 App 里随时给机器人发链接，看板开着就会自动入库

## 常见问题

**Q: 控制台显示"钉钉 Stream 连接失败"？**
- 检查 AppKey/AppSecret 是否复制完整（不要带空格）
- 确认机器人「消息接收模式」选了 **Stream 模式**（不是 HTTP 模式）
- 确认应用已「发布」

**Q: 发消息机器人没反应？**
- 看控制台有没有打印 `[dingtalk] Stream 客户端已连接`
- 看控制台有没有收到消息的日志
- 确认你发的是给「机器人」私聊，不是普通联系人

**Q: 想同时用企业微信和钉钉？**
- 可以！两个环境变量组都配上，启动时会同时启用
