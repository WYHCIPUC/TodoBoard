# 灵感工作台 2.0.0 Beta 2

这是一次围绕“稳定保存、明确状态、形成决策闭环”的升级。Windows 用户推荐下载单文件 EXE，双击即可运行，无需安装 Node.js 或解压。

## 推荐下载

- `linggankanban-2.0.0-beta.2-windows-x64.exe`：Windows 10/11 x64 单文件版。
- `linggankanban-2.0.0-beta.2-windows-portable-x64.zip`：便携目录包。
- `SHA256SUMS.txt`：下载完整性校验值。

## 本次重点

- 头脑风暴方案可保存为本地 Markdown，并在工作台查看最近记录和下载复盘。
- 服务状态不再只靠一个颜色点，断线缓存会明确标记为只读并禁用写操作。
- 数据覆盖前必须成功创建备份，写入执行落盘同步，失败不会破坏原文件。
- 未捕获异常会记录并安全退出；退出时等待现有请求结束。
- 快速切换头脑风暴目标或视角时会取消旧请求，避免过期结果覆盖当前分析。

用户数据继续独立保存在“文档\LingganKanban”，替换 EXE 不会覆盖已有收藏、研究档案和头脑风暴方案。

当前为 Beta 预发布版本，Windows EXE 尚未进行商业代码签名。请仅从本仓库 Release 下载，并使用 `SHA256SUMS.txt` 核对文件完整性。
