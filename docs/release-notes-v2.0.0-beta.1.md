# 灵感工作台 2.0.0 Beta 1

这是“灵感来袭 + 头脑风暴”双核心版本。普通 Windows 用户推荐下载单文件 EXE，双击即可运行，无需安装 Node.js，也无需解压。

## 推荐下载

- `linggankanban-2.0.0-beta.1-windows-x64.exe`：Windows 10/11 x64 单文件版。
- `linggankanban-2.0.0-beta.1-windows-portable-x64.zip`：可查看完整目录的便携包。
- `SHA256SUMS.txt`：下载完整性校验值。

单文件版首次运行会准备内置环境，完成后自动打开浏览器。数据独立保存在“文档\LingganKanban”，后续替换 EXE 不会覆盖现有收藏和研究档案。

## 本次重点

- 灵感收集与头脑风暴升级为同级的双核心工作流。
- 从真实需求出发，融合多个已收藏项目的能力、审美与方法，生成有依据的方案和最小验证步骤。
- 全新的成熟应用布局、数据管理、备份恢复、重复治理、书签导入和移动端体验。
- 本地 Markdown 数据源，无需云账号或数据库。

当前为 Beta 预发布版本，Windows EXE 尚未进行商业代码签名。请仅从本仓库 Release 下载，并使用 `SHA256SUMS.txt` 核对文件完整性。
