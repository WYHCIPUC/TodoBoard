# 灵感工作台 2.0.0

这是首个稳定版，面向 Windows 10/11 x64 用户提供无需安装 Node.js 的单文件程序。

## 下载

- `linggankanban-2.0.0-windows-x64.exe`：推荐，双击即可运行。
- `linggankanban-2.0.0-windows-portable-x64.zip`：便携目录包。
- `linggankanban-2.0.0-windows.zip`：需要自行安装 Node.js 20+ 的源码运行包。
- `SHA256SUMS.txt`：以上三个文件的 SHA-256 校验值。

## 稳定版能力

- 本地收集网页、GitHub、Bilibili 等链接，保存元数据、正文、笔记和截图。
- 列表与看板双视图、全文搜索、研究模板、重复治理、回收站及完整备份恢复。
- 需求驱动的头脑风暴与融合方案，可保存为本地 Markdown。
- 数据默认保存在“文档\LingganKanban”，替换程序文件不会覆盖个人数据。
- 无需注册、登录、激活或联网验证，下载后可永久使用当前版本。

## 已知限制

- 目前只提供 Windows x64 成品；外部网页解析结果受目标网站和本地网络影响。
- EXE 尚未进行商业代码签名，Windows 可能显示 SmartScreen 提示。请从可信地址获取文件，并核对 `SHA256SUMS.txt`。
