# 公开 Beta 首次使用测试

目标是验证一位不熟悉项目的 Windows 用户能否在 5 分钟内完成首次收藏，并知道数据在哪里、如何备份。主持人只观察，不提前解释界面。

## 测试对象

- 5 至 8 名经常收藏技术文章、项目或视频的个人用户。
- 至少 3 名不熟悉 Node.js 或命令行。
- Windows 10 与 Windows 11 都应覆盖。

## 测试任务

1. 根据发布页完成安装并打开看板。
2. 收藏主持人提供的一条网页链接。
3. 为链接填写标签和“为什么收藏”。
4. 打开研究页，选择合适模板并记录一条关键发现。
5. 通过搜索重新找到该条目。
6. 删除条目，再从回收站恢复。
7. 找到数据管理并导出完整备份与诊断信息。
8. 说出数据健康状态，并通过右上角帮助入口重新打开上手指引。

## 记录指标

- 从解压到看到看板的时间。
- 从看到看板到首次收藏成功的时间。
- 每一步是否独立完成、求助次数和放弃点。
- 解析是否成功，失败后是否理解降级结果。
- 用户能否说清数据位置、备份方法和删除是否可恢复。
- 任务结束后的 1 至 5 分易用性评分与继续使用意愿。

## Beta 通过建议

- 80% 的用户在 5 分钟内完成首次收藏。
- 90% 的用户能独立找到备份入口。
- 不出现数据丢失、错误恢复或端口暴露问题。
- 同一阻塞点被两名以上用户遇到时，进入下一补丁版本的最高优先级。
