# 灵感工作台 v2.3 更新视频设计

## 目标与边界

- 用途：GitHub Release 与项目主页，30 秒内说明 v2.3 相比上一版真正补齐的内容。
- 受众：需要长期收藏、整理和复用网页信息的个人用户。
- 叙事：收藏入口更清楚，关系整理真正可操作，头脑风暴形成决策闭环，所有数据仍保存在本机。
- 规格：1920×1080、30fps、900 帧、无旁白；交付 BGM + SFX 与仅 SFX 两版。
- 数据：只使用隔离的虚构演示数据；不读取、拍摄或打包仓库 `DATA.md`。

沿用产品的暖纸、墨黑、陶土橙和鼠尾草绿。真实界面始终正视并保持文字可读，更新提示使用短时品牌色画框，不使用持续抖动、群发扫光或无意义漂浮。
