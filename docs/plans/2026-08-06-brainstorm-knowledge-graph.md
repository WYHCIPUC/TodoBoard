# 头脑风暴知识图谱设计

## 目标

把 `DATA.md` 中相互孤立的待研究事项转换为可解释的关联网络，并给出能够回溯到原始条目的项目建议。分析只在本机执行，不调用外部 AI，也不修改用户数据。

## 数据与评分

- 节点：条目编号、标题、分类、状态、难度和研究档案覆盖情况。
- 特征：标题、标签、有效业务字段与 `notes.md`；正文只用于判断档案覆盖，不直接主导关联。
- 边：共同标签、共同关键词、同源站点、同分类、跨分类、难度差和研究状态共同提供权重，并标注主题、来源、同类对照、跨域、互补和进阶等关系类型。
- 降噪：过滤 Markdown 模板词、链接字段以及在大量条目中重复出现的高频词。
- 图谱约束：每个节点最多保留七条高质量边，在增加碰撞广度的同时避免形成不可读的毛线团。

## 产品层级

头脑风暴不是统计弹窗，而是与“灵感来袭”平级的第二核心工作台。顶栏使用“灵感工作台”作为产品容器，一级导航在“灵感来袭（收集与研究）”和“头脑风暴（关联与决策）”之间切换。头脑风暴采用独立全页布局，承载多维雷达、全景网络、跨域矩阵和建议流。

## 需求驱动融合

默认入口不是给出一组泛化结论，而是要求用户先描述一个实际需求、使用场景或偏好。系统随后：

1. 扩展需求中的领域词和能力词，在全部待研究事项中形成候选集。
2. 为每个候选项目提取可复用的长处，并解释它为什么与当前需求有关。
3. 尽量选择承担不同能力角色的项目，避免只把相似项目堆叠在一起。
4. 生成推荐路径、轻量验证和差异化扩展三类融合方案。
5. 为首选路径给出可直接执行的最小验证步骤。

例如，需求为“制作符合个人偏好的网站设计 Skill”时，可以从网站动效项目提取自动动效和页面生成能力，从高分网页案例库提取审美样本和交互风格，再引入结构图与自动化执行能力，组合成“偏好样本—设计规则—结构生成—落地验证”的新方案。

## 分析维度

1. 主题共振：发现关键词、标签与研究语义重叠。
2. 跨域碰撞：寻找不同分类之间的方法迁移与场景组合。
3. 能力互补：识别可拼接成完整输入—处理—输出链路的事项。
4. 来源生态：观察同平台、同作者生态与同类项目来源。
5. 研究进阶：结合难度、状态和关联强度安排研究顺序。
6. 同类对照：把重复收藏转化为统一指标下的比较选型。
7. 主题组合：把多个事项提升为持续经营的专题或产品方向。

## 建议类型

1. 组合项目：优先寻找跨分类强关联，提出最小可验证原型。
2. 跨域迁移：把一个领域的方法迁移到另一个真实场景。
3. 对比评测：把同类收藏放进统一指标体系形成选型结论。
4. 专题产品：从较大的关联簇中提炼持续研究主题和统一评测维度。
5. 成果复用：用已完成事项的结论加速相关待研究事项。
6. 快速验证：优先安排低成本、能提升网络密度的短实验。
7. 盲区诊断：识别孤立项、证据缺口与可能的新方向。
8. 研究路线：按连接度、状态和难度安排连续实验顺序。

每条建议必须包含置信度、关联信号、原始条目证据和最小验证步骤。数据不足时明确提示补充标签或收藏原因，不强行生成结论。

## 技术选择

当前规模使用原生 JavaScript 完成分词、边评分、连通分量和 SVG 展示，以保持零构建、低依赖和便携包体积。模型与数据结构兼容通用的 `nodes + edges` 形式，未来数据量显著增长时可以迁移到：

- [Graphology](https://github.com/graphology/graphology)：通用 JavaScript 图数据结构和算法库。
- [Cytoscape.js](https://github.com/cytoscape/cytoscape.js)：成熟的图分析与交互可视化方案。
- [force-graph](https://github.com/vasturiano/force-graph)：适合大规模 Canvas 力导向图的交互渲染。

## 验收标准

- 空数据、单条记录和多分类记录均能稳定返回。
- 需求融合至少返回多条不同路径，并说明每个来源项目贡献的长处和命中依据。
- “网站动效神器 + 高分网页大赏”示例能够形成个性化设计 Skill 的可执行 MVP。
- 建议不会使用“简介、难度、封面”等模板词作为核心依据。
- 桌面与 390px 宽度均无横向溢出。
- 点击图谱节点或证据条目可以进入对应研究档案。
- API 只读，并沿用现有会话认证与限流策略。
