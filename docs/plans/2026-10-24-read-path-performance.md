# 读取路径性能与上限透明化升级

**状态**：已完成（2026-10-24）<br>
**基线**：v2.3.0（`3732e7b`）<br>
**范围**：读取路径与结果说明，不新增产品功能，不改数据格式，不删除既有接口字段<br>
**依据**：[项目原则](../PROJECT-PRINCIPLES.md)、[原则对照与补强计划](2026-08-14-principles-gap-analysis.md) 中 D1「批量读取归档状态」、D2「为搜索建立可失效的本地缓存」、C「分析上限未显式提示截断」

## 背景与证据

当前版本在读取路径上有三处与规模相关的缺口，均可在源码中定位：

1. **归档状态 N+1 请求**：服务端已提供批量接口 `GET /api/archive/statuses`（`server.js`），但浏览器端 `loadArchiveStatuses()` 仍逐条请求 `GET /api/archive/status?id=`。默认 `API_RATE_LIMIT=300`，条目接近或超过 300 时一次刷新就会触发 429，被限流的条目静默停留在默认「排队中」，用户看到的归档状态不再可信。
2. **深度搜索无缓存**：`/api/search` 每次查询都会对每条目重新读取 `notes.md` 与 `archive/content.md`（单文件上限 1 MB）。客户端防抖 250 ms，但连续输入仍会反复解码大量磁盘内容，条目越多越明显。
3. **头脑风暴静默截断**：`lib/brainstorm.js` 以 `MAX_ITEMS = 300` 截取条目参与分析，`summary.items` 直接等于截断后的数量，接口与界面都没有说明「还有多少条目未参与」，与原则 5「结论带出处、证据不足要明示」不一致。

附带两处同源重复读取：

- `GET /api/attention` 先由 `archiveStatuses()` 读取并校验一次 `DATA.md`，再由 `aggregateAttention()` 读取第二次；两份内容可能来自不同时点。
- 批量归档状态把 `lastError` 收敛为 `{ code }`，而客户端错误文案函数只处理字符串；直接切换批量接口会把「最近错误」显示成 `[object Object]`。

## 提案

### A. 归档状态批量读取（`board.js`）

- 首次加载、刷新与恢复连接后只发一次 `GET /api/archive/statuses`，按 `id` 合并到当前条目。
- 只有服务端明确不支持该接口（404/405，例如浏览器缓存了旧服务端）时才回退到逐条读取；回退并发上限 4，避免旧服务端再次出现请求风暴。
- 网络失败、限流（429）或服务错误时**保留上一次状态并按原样渲染**，不再在失败时用默认「排队中」覆盖已有状态。
- 批量返回的 `lastError` 可能是对象，客户端优先读取 `message`/`code`，服务端同时保留短消息与稳定 code。

### B. 深度搜索文件缓存（`lib/search.js`）

- 新增模块内缓存，按「绝对路径 + 读取上限 + 截断策略」索引，条目记录 `mtimeMs/ctimeMs/size`。
- 命中前必须重新 `stat` 并比对三项元数据；文件被替换、删除或改变大小都会自动失效，无需跨模块回调。
- 缓存有界：最多 512 个文件、最多 32 MiB 文本，按最近最少使用淘汰；单次读取失败不缓存。
- 读取语义与现状一致：`notes.md` 超限截断，正文超限跳过（正文原本会抛错并被搜索忽略）。

### C. 头脑风暴上限透明化（`lib/brainstorm.js`）

- `analyze()` 只扫描一次数据，向 `buildNodes()` 传入已解析条目，并在 `summary` 中增加 `totalItems` 与 `truncated`。
- 发生截断时在 `insights` 中追加一条可读说明，现有界面直接渲染该字段，无需新增 UI 组件。
- 保存为 Markdown 的方案在「本轮分析依据」中记录「项目库共 N 条、仅分析前 M 条」，避免离线证据丢失上下文。
- `items` 仍表示「参与分析的数量」，保持既有消费者语义。

### D. 待处理中心单次读取（`server.js`）

- `archiveStatuses()` 接受可选数据文本；`GET /api/attention` 读取一次 `DATA.md` 并同时传给归档状态与注意力聚合，避免同一请求内出现两个时点。

## 数据、网络与失败边界

- **用户数据**：全部改动只读现有本地文件；不新增写入格式，不改 `DATA.md`、档案目录或备份结构。
- **网络**：仍只有用户主动刷新/搜索触发本地接口；批量接口不产生新的出站请求，反而减少本机请求数。回退路径也只访问本机服务。
- **失败降级**：批量接口失败时保留上一次已知状态，并仅在接口缺失时回退逐条读取；搜索缓存失效时退回直接读取；头脑风暴上限说明只影响展示，不改变分析结果。
- **恢复**：无需数据迁移，回滚只需还原相应文件。
