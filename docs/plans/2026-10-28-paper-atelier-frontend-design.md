# 纸间灵感研究室：前端设计升级

**日期**：2026-10-28

## 设计概念

一座以本地研究档案为核心的纸间工作台。第一印象应当是安静、温暖、可信，让用户愿意把散落线索整理成研究结论。

视觉记忆点不是营销口号、渐变大卡片或装饰插画，而是编辑式细分隔线、编号索引、衬线标题与真实条目元信息。强调色优先服务收藏、当前步骤和关键状态。

## 保留与重设

- 保留本地 Markdown 数据、九种分类、三阶段工作流、图标语义、快捷键、归档和可信恢复。
- 保留无框架浏览器模块，不引入 UI、字体、图标或动画依赖，不请求远程字体。
- 重设首屏比例：标题直接使用“灵感项目库”，减少非内容区域，让真实收藏更早进入视野。
- 重设列表与看板：摘要、分类、来源、难度、状态和归档状态在同一阅读顺序中呈现。
- 重设关系与头脑风暴：关系图按真实节点范围缩放；需求、证据、推荐方案与验证步骤各有清楚层级。
- 重设研究档案：桌面双栏、移动单栏，归档、截图、原文与保存操作不减少。

## 数据、失败与恢复边界

本次只修改浏览器展示、交互反馈、测试和发布资料，不修改 API、路由、Markdown 数据格式或存储事务。

- 不读取或改写真实 `DATA.md`；浏览器验证使用公共示例或临时副本。
- 不增加出站请求；远程封面继续遵循已有 referrer 策略，核心数据不上传。
- 网络失败、只读服务、归档降级和离线基础关系仍明确显示，不以视觉成功态掩盖失败。
- 恢复预览、确认、备份、回滚、未保存笔记保护和幂等写入均保持原流程。
