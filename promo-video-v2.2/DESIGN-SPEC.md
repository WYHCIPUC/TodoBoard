# 灵感工作台 v2.2 介绍视频设计规范

## 产品简报与执行约束

- 用途：GitHub Release 与产品介绍页首发，帮助第一次接触产品的人在 30 秒内理解价值。
- 受众：有大量链接收藏、需要长期研究与整理的个人用户。
- 核心叙事：把容易失效的链接，沉淀成可恢复、可继续思考的本地知识资产。
- 必须展示：链接收集、主动备份、搜索与研究档案、恢复可信状态、头脑风暴、本地桌面版。
- 规格：1920×1080，30fps，900 帧，简体中文，无旁白。
- 数据：只使用 `video-demo-data.md` 驱动的隔离本地 Demo；不读取或拍摄仓库 `DATA.md`。
- 音频：电子纸墨质感 BGM + 克制的电影系 SFX；终渲同时交付 BGM 版与无 BGM 版（保留 SFX）。

## 视觉与动效方向

候选方向：① 暖纸档案馆；② 深色数据中枢；③ 轻盈创意杂志。最终选择“暖纸档案馆”，它与产品现有暖白、墨黑、陶土橙、衬线标题和本地可信语义最一致。暗场只用于链接失效的 1 个短镜头。

| Token | 取值 |
|---|---|
| 纸底 | `#f6f0e7` / `#fffaf3` |
| 墨色 | `#292621` |
| 强调色 | `#c86f43` |
| 成功色 | `#52755f` |
| 标题 | Georgia / Noto Serif SC，压印感 |
| 正文 | Inter / Microsoft YaHei，清晰克制 |
| 光感 | 中心暖光、细颗粒、极轻 vignette |
| 动效性格 | 亲和友好向专业信赖收拢：主入场约 26f，无大幅弹跳，落位过冲 ≤1.04，转场 16–24f |

动效关键词：沉着、可信、精致。所有页面镜头以正视阅读为主，仅在卡片入库和头脑风暴段使用轻 2.5D。禁用随机抖动、群发 glint 和手持 shake。

## 功能到镜头映射

| 功能 | 首选镜头卡 / 变体 | 取舍依据 |
|---|---|---|
| 品牌建立 | `brand-ink-open` | 纸墨压印与现有 UI 同源，低能量开场 |
| 链接进入项目 | `deck-deal-flyin` | “源源不断汇入”的物理隐喻；缩减为 8 张真实卡片 |
| 搜索进入档案 | `type-and-filter` | 唯一真人操作镜头，交代可找回、可继续研究 |
| 主动备份 | `ai-stream-response` | 用“结论先到、证据随后”表达归档流水线，正视保证可读 |
| 章节呼吸 | `paper-title-card` | 纸墨字卡明确从收藏转向思考 |
| 头脑风暴 | `canvas-materialize-moves / diagram-cascade` | 连线先行、节点级联，直观表达从项目长处长出方案 |
| 品牌收尾 | `ui-to-brand-morph / input-morph-assemble` | 搜索框收束为产品标识，形成 UI→品牌因果 |

## 音频与节拍执行表

- BGM：Mixkit `House Vibez`，约 123 BPM，版权来源见 `public/audio/ATTRIBUTION.md`。
- 主切点：f91 / f180 / f327 / f416 / f534 / f593 / f755，均落在最近拍点 ±3f 内。
- SFX：打字 f337、搜索点击 f393、归档证据 f471/f494、价值字卡 f538、收尾 riser f773 → impact f833 → sparkle f859。所有 SFX 均显式设置 `durationInFrames`。
- 交付：带 BGM 主版本，以及从同一主版本视频轨无损复用、仅替换为 SFX 音轨的无 BGM 版本。

## 放行记录

产品简报、数据边界、视觉方向、功能映射和 900 帧时间轴一致；没有遗漏用户要求的“本地、桌面、主动备份、稳定恢复、头脑风暴”。设计规范于自主自由创作模式下放行，进入最终素材采集。
