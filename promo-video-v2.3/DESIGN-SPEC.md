# 灵感工作台 v2.3 更新视频设计规范

## 产品简报

- 用途：GitHub Release 与项目主页，30 秒内说明 v2.3 的真实更新。
- 受众：希望长期收藏、整理并复用网页信息的个人用户。
- 核心叙事：一个中心、三个阶段——灵感来袭负责收集，关系画布负责整理，头脑风暴负责融合决策。
- 必须展示：明确的新增入口、先保存后解析、主动本地归档、X / GitHub 解析降级、关系画布、来源驱动的头脑风暴、桌面与本地数据。
- 规格：1920×1080、30fps、900 帧、简体中文、无旁白；交付 BGM + SFX 和仅 SFX 两版。
- 数据：只使用 `video-demo-data.md` 驱动的隔离演示数据，不读取或拍摄仓库 `DATA.md`。

## 视觉与动效方向

沿用产品的暖纸、墨黑、陶土橙和鼠尾草绿，以正视真实界面作为证据。动效服务于输入、点击、解析进度、节点落位和章节换挡；禁止持续抖动、随机闪光、无意义漂浮和遮挡正文的装饰。

| Token | 取值 |
| --- | --- |
| 纸底 | `#f6f0e7` / `#fffaf3` |
| 墨色 | `#292621` |
| 主强调 | `#c84c18` |
| 完成色 | `#52755f` |
| 标题 | Georgia / Noto Serif SC |
| 正文 | Inter / Microsoft YaHei |
| 节奏 | 123 BPM 主切点，16–24 帧过渡，克制 spring |

## 镜头动作与功能映射

下表中的名称是本片自定义镜头变体，用来记录动作意图，不表示必须逐项复刻外部模板。最终实现以“真实界面证据清楚、动作与功能状态对应”为验收依据。

| 功能 | 镜头卡 / 变体 | 设计理由 |
| --- | --- | --- |
| 更新开场 | `trailer-bumper` | 三个真实页面快速建立更新规模，再落版标题 |
| 三阶段主线 | `paper-title-card` + stagger | 一屏交代产品中心与三个阶段的职责 |
| 收藏与归档 | `capture-modal-and-proof` | 左侧真实新增弹层进入，右侧保存与归档证明逐项出现 |
| 解析降级 | `parallel-fallback-status` | GitHub 与 X 的公开降级路径并行呈现，明确失败不丢链接 |
| 关系画布 | `canvas-focus-and-tags` | 真实画布由虚到实，功能标签逐项进入，保留界面可读性 |
| 头脑风暴 | `diagram-cascade` | 根节点到方案再到验证步骤逐层生长 |
| 更新收尾 | `workspace-pages-to-brand` | 三个真实页面汇聚并后退，工作台字标接管视觉中心 |
